# TU Arts Dashboard — Revision 4

ระบบต้นแบบบริหารภาระงานและการลา สำหรับเปิดใน VS Code

## เปิดใช้งาน
1. แตก ZIP แล้วเปิดโฟลเดอร์ `TU_Arts_Dashboard_Revision4` ใน VS Code
2. เปิด `index.html` ผ่าน Live Server
3. เลือกบัญชีทดสอบและกดเข้าสู่ระบบ

ไม่ต้องติดตั้ง Node.js หรือฐานข้อมูลเพื่อใช้เว็บไซต์
โปรดใช้โฟลเดอร์ทั้งชุดนี้ ไม่คัดลอกเฉพาะ app.js ไปปนกับรุ่นที่มี script.js/layout.js

## ข้อมูลเดิม
- ใช้ storage key เดิม `tu_arts_dashboard_v5` และ session key `tu_arts_dashboard_session`
- รุ่นนี้ไม่มีคำสั่งล้างข้อมูลเดิมหรือรีเซ็ตข้อมูลจำลองอัตโนมัติ
- localStorage แยกตามเบราว์เซอร์ โปรไฟล์ โปรโตคอล ชื่อโฮสต์ และพอร์ต การเปลี่ยนจาก localhost เป็น 127.0.0.1 หรือเปลี่ยนพอร์ต อาจทำให้ดูเหมือนข้อมูลหาย
- เปิดด้วยเบราว์เซอร์และ URL ต้นทางเดียวกับรุ่น TU_Arts_Dashboard เดิม เมื่อต้องการใช้ข้อมูลเดิม
- รุ่นก่อน Dashboard ที่ใช้ storage key อื่นไม่ได้ย้ายข้อมูลเข้ามาอัตโนมัติ
- หากข้อมูลที่เก็บไว้เสียหาย ระบบไม่เขียนทับด้วยข้อมูลจำลองใหม่

## การปรับปรุงรอบนี้
- เมนูเลือกบัญชีแบบกำหนดเอง: หัวข้อกลุ่มงานสีดำและตัวหนา รองรับคีย์บอร์ดและหน้าจอแคบ
- ใช้ไอคอน SVG ของภาระงาน ระบบลา เมนูสามขีด และออกจากระบบ ไม่พึ่งไอคอนจาก CDN
- ปุ่มเมนูยุบ/ขยาย Sidebar บนคอมพิวเตอร์ และเปิด/ปิดแถบเลื่อนบนมือถือ
- ช่องตัวกรองความสูง 44 พิกเซล ความกว้างเท่ากันในแถวเดียวกัน ปรับจำนวนคอลัมน์ตามขนาดหน้าจอ
- ตัวกรองแสดงรายการอยู่ข้างหัวข้อตัวกรองภาระงาน พร้อมปุ่มล้างตัวกรองขนาดกะทัดรัด
- หน้าภาระงานใช้เฉพาะงานของฉันและงานที่รับโอน งานของบุคลากรดูผ่านภาพรวมตามสิทธิ์
- ป้าย "ดำเนินงานข้ามฝ่าย" ขนาดเล็ก แสดงเมื่อกลุ่มงานเจ้าของกับผู้ถือครองปัจจุบันแตกต่างกัน
- วันที่ใช้รูปแบบ `18 พ.ย. 69 – 25 พ.ย. 69` สีดำและขนาดเดียวกันทั้งสองฝั่ง ขั้นตอน Workflow ใช้สีดำขนาดเดียวกับวันที่
- กราฟใช้ส้มอ่อน ความเข้มสัมพันธ์กับจำนวนงาน แท่งที่เลือกใช้ส้ม–ดำไล่ระดับ
- ปฏิทินงานมี วัน/เดือน/ปี โดยแสดงเฉพาะวันที่ ไม่มีตารางชั่วโมง
- ปฏิทินลาแยกส่วนตัวกับบุคลากร ส่วนบุคลากรใช้เฉพาะเจ้าของคำขอที่ผู้ใช้งานมีสิทธิ์พิจารณา ไม่แสดงทุกคนโดยไม่มีขอบเขต
- ตารางลารายวันแสดง 00:00–23:00 เสมอ รวมวันว่าง รายการอยู่ตามเวลาเริ่ม–สิ้นสุดจริง รองรับหลายรายการที่เวลาทับกัน
- คำอธิบายสีปฏิทินงาน: เสร็จสิ้น / รอดำเนินการ / เกินกำหนด (งานที่ยังไม่เสร็จและไม่เกินกำหนดใช้สีรอดำเนินการ)
- คำอธิบายสีปฏิทินลา: อนุมัติแล้ว / รออนุมัติ / ไม่อนุมัติ ไม่มีคำว่า "รายการทั่วไป"
- การพิจารณาคำขอลาอยู่แท็บแยกจากปฏิทิน มีตัวกรองสถานะ ปี เดือน และประเภท
- แบบฟอร์มยื่นลาอยู่กึ่งกลางพื้นที่เนื้อหา
- เลขานุการคณะยังยื่นลาได้ แต่ไม่มีบัญชีผู้อนุมัติระดับถัดไปในต้นแบบ และไม่อนุมัติตนเอง เลขานุการดูงานแบบติดตาม ไม่เพิ่มภาระงานหรือเปลี่ยนขั้นตอนแทนผู้อื่น

## การส่งออกและข้อจำกัด
การส่งออกยังใช้ `.xls` และ `.doc` แบบ HTML-compatible ตามรุ่นก่อน ไม่ใช่ native `.xlsx`/`.docx` โปรแกรม Office อาจแจ้งเตือนว่านามสกุลไม่ตรงกับเนื้อหา ต้องตรวจรายงานก่อนใช้งานจริง โลโก้ฝังเป็นภาพในเอกสารแล้ว แต่การแสดงผลขึ้นกับโปรแกรมที่เปิดรายงาน ฟอนต์ TH Sarabun New 16 pt ต้องติดตั้งอยู่บนเครื่องผู้ใช้ ไม่มีไฟล์ฟอนต์แนบมา

ระบบนี้ใช้บัญชีจำลองและ localStorage การซ่อนปุ่ม/กรองข้อมูลไม่ใช่มาตรการรักษาความปลอดภัยฝั่งเซิร์ฟเวอร์ จึงไม่ควรใช้เก็บข้อมูลบุคลากรจริง ไม่มีการซิงก์ข้ามอุปกรณ์
